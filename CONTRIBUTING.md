# Contributing

All contributions are greatly appreciated — whether adding new plugins, updating existing ones, or improving anything else.

## Adding a New Plugin

When adding a new plugin, please make sure to follow the same style:

| Plugin | Feature | Support | License |
|--------|---------|---------|---------|
| [plugin-name](repo-url) | Description of what it does | Supported providers. [Install](link-to-install-guide) | [LICENSE](license-url) |

> The Install URL can point to a section within a README, such as `repository#installation`.

- Use the official repository link, preferably to it's GitHub repository.
