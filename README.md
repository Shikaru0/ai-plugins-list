# ai-plugins-list
A curated list of plugins for AI agents.

## List
Plugin | Feature | Support
--- | --- | ---
[ponytail](https://github.com/DietrichGebert/ponytail) | Makes your AI agent think like the laziest senior dev in the room. The best code is the code you never wrote. | Claude Code, Codex, Opencode, Gemini CLI, Github Copilot CLI, Pi harness, and more. [Install](https://github.com/DietrichGebert/ponytail/blob/main/INSTALL.md)
[caveman](https://github.com/JuliusBrussee/caveman) | Caveman make your AI agent say less and read less. Code stay exact. Brain still big. | Claude Code, Codex, Opencode, Gemini CLI, Github Copilot CLI, OMP; supports almost every agent. [Install](https://github.com/JuliusBrussee/caveman/blob/main/INSTALL.md)
[impeccable](https://github.com/pbakaus/impeccable) | Helps AI agents produce better frontend UI through design principles, guidelines, and reusable skills for visual quality and consistency. | Claude Code, Codex, Opencode, Github Copilot App (built-in), and more. [Install](https://github.com/pbakaus/impeccable/blob/main/README.md#Installation)
