A curated list of plugins for AI agents.

Plugin | Feature | Support | License

[Install](https://github.com/JuliusBrussee/caveman/blob/main/INSTALL.md) | [Apache License 2.0](https://github.com/JuliusBrussee/caveman/blob/main/LICENSE)
[impeccable](https://github.com/pbakaus/impeccable) | Helps AI agents produce better frontend UI through design principles, guidelines, and reusable skills for visual quality and consistency. | Claude Code, Codex, Opencode, Github Copilot App (built-in), and more.
